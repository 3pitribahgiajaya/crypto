# Security policy and limitations

## Data and credentials
This is a static client-side application. It has no user authentication backend, server session, or credential vault. Portfolio notes are stored in localStorage on the current browser/device. Do not use on shared devices for sensitive information.

## Wallet
The application requests account access from an injected EIP-1193 wallet and reads native balance/network. It does not request seed phrases or private keys, sign messages, call eth_sendTransaction, approve tokens, or submit transactions. Always verify the domain before connecting a wallet.

## Exchange / Ajaib
No Ajaib API integration or authenticated broker connection is present. Never provide Ajaib passwords, OTPs, recovery codes, or API credentials to this static website. Any future broker integration must use an officially documented API and a trusted backend with least-privilege keys, withdrawals disabled, audit logging, rate limiting, and explicit trade confirmation.

## Third parties
Market data comes from CoinGecko public endpoints. ethers.js is loaded from jsDelivr. These providers may observe requests and change service availability. Market data is informational and may be delayed.

## Notifications
Browser notifications are generated by the open page only. No background push server or notification subscription backend is configured.

## Reporting
Do not publish credentials or exploit details in public issues. Rotate any secret accidentally committed to Git history.
